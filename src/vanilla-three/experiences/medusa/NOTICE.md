# Medusa — source acknowledgements

The oil-bristle atlas in `brushAtlas.ts` is adapted from **Chimera**, by
**Michael Kozlowski (mpkoz)**.

- Original: https://www.artblocks.io/collection/chimera-by-mpkoz

  (https://creativecommons.org/licenses/by-nc/4.0/).

Changes: a seeded atlas stream; direct CanvasTexture upload; a new Three.js TSL
painter using camera-facing stamps attached to procedural jellyfish anatomy;
new pigment fields, filtered grain, pose deformation, anatomical emergence,
controls and presentation. The adapted
material retains the original attribution and noncommercial licence. No
endorsement by the original artist is implied.

**Aurelia**, by **holtsetio**, informed the relationship between the contracting
bell, directional attachment points and freely trailing anatomy:
https://github.com/holtsetio/aurelia (MIT).
No Aurelia code or assets are incorporated. Medusa uses a separate, fixed-step
CPU constraint model and GPU paint deformation rather than Aurelia's GPU Verlet
implementation and physical materials.
